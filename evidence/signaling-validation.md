A subsequent unit regression verifies duplicate peer-disconnect deadlines do not accumulate or expire a resumed peer early; `MUSOU_REPORT_SUFFIX=-signaling-final npm run test:e2e -- e2e/rooms.spec.ts` then passed all three room tests on the final implementation (29.0 seconds).
